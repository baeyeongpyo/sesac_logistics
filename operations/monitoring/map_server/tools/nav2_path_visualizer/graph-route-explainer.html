Router가 고른 Lane의 geometry를 순서대로 연결합니다. 이 결과가 Nav2의 controller가 참조할 차량 추종용 전역 Path입니다.

Planner는 Router가 정한 Lane을 바꾸지 않습니다. 주행 중 속도·장애물 판단은 그 다음 Controller의 역할입니다.

대기 중 · 지도에서 차량의 현재 위치를 선택하세요.

지도 클릭은 Graph Node 선택

화면에서는 클릭 waypoint가 곧 Node입니다. 실제 시스템은 임의 좌표를 가장 가까운 허용 Node 또는 Lane 진입점에 스냅할 수 있습니다.

ROUTER ≠ PLANNER

RoutePlan은 Lane ID 순서, Path는 pose 순서

Router의 결과는 lane-01 → lane-05 → lane-06처럼 어떤 통로를 사용할지입니다. Planner는 선택된 Lane의 좌표를 연결해 nav_msgs/Path를 생성합니다.
