Fleet Manager가 목표를 보내면, BT Navigator가 절차를 실행하고 NavFn이 지도 전체 경로를 만듭니다. DWB는 그 경로와 현재 센서 지도를 기준으로 지금 보낼 속도를 고릅니다.

중요: 이 페이지는 현재 NavFn + DWB 구성을 설명합니다. TEB는 사용 중이 아니며, 기본 BT에는 통로 후진 이탈 절차가 아직 들어 있지 않습니다.

WHO DECIDES WHAT

판단의 책임은 층마다 다릅니다.

“어떻게 지나갈지”와 “지금 어떤 속도를 낼지”는 같은 판단이 아닙니다.

A / FLEET POLICY

작업·통로 정책

Fleet Manager는 통로를 쓸지, 예약을 기다릴지, 어떤 순서로 작업을 수행할지를 결정합니다.

  • task / lane_id / mode 같은 업무 의미
  • 통로 예약과 로봇 선택
  • 현재는 목표 하나만 전송
B / NAV2 PROCEDURE

주행 절차

BT Navigator는 어떤 Nav2 행동을 어떤 순서로 실행할지 정합니다. 현재 기본 트리는 경로 생성과 추종만 연결합니다.

  • ComputePathToPose @ 1 Hz
  • FollowPath로 이어지는 기본 흐름
  • BackUp·DriveOnHeading은 서버에 준비됨
C / LOCAL CONTROL

즉시 주행 판단

DWB는 현재 자세·로컬 costmap·전역 경로를 보고 여러 속도 후보 중 충돌하지 않는 궤적을 고릅니다.

  • 15 Hz, vx: −0.08 ~ 0.22 m/s
  • 경로·목표·장애물 critic
  • 업무상의 lane 의미는 알지 못함
