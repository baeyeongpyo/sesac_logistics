NavigateToPose action

유효한 Goal x, y, yaw 값을 입력하면 실행 명령을 생성합니다.

Nav2는 yaw 값이 아니라 quaternion orientation을 받습니다. 다중 차량은 실제 action 경로와 frame_id를 차량 namespace에 맞게 바꾸세요.
