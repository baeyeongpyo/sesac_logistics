# 4회 — 현장 낭독

검토본: draft-v3.md.

핵심 판단: 3회에서 지적한 재이송 조건(35행), 관제 정의(31·77행), 시험 도입 설명(157~163행)이 개선됐다. 이번에는 원고를 기준으로 청중의 시선과 낭독 흐름을 점검했다.

1. 시선 전환을 더 선명하게 한다. 91행에서 두 장치를 동시에 시작하지만 청중은 팔레트를 집는 차량부터 본다. 로봇암의 핵심 동작이 그 사이 끝나지 않도록 담당자 간 순서를 맞추고, 차량 주행 중 로봇암을 안내한다. 105행의 확장 예고는 시연 뒤로 옮기고 관찰 안내를 짧게 한다.

2. 하역 결과는 한 항목씩 보여준다. 119~121행은 실물 하역, P3 재고, 작업 완료, 차량 적재 상태를 연달아 말한다. 청중이 화면의 해당 항목을 찾는 사이 설명이 끝날 수 있다. 팔레트가 내려놓인 것을 먼저 가리키고, 화면의 목적지 재고와 차량 적재 상태를 순서대로 짚은 뒤 잠시 관찰하게 한다. 숫자나 작업 ID를 읽을 필요는 없다.

3. 20분을 지키는 축약 위치가 늦다. 91·111행에서 이동 약 2분과 전체 작업 시간을 구분한 것은 좋지만, 179행의 마무리 지시만으로는 시연 지연을 흡수하기 어렵다. 5분 안에 적재·하역·확인·별도 정지·취소가 들어가는지는 리허설이 필요하다. 지연 시 151~155행의 반복 배경 설명을 축약하고 157~163행의 고객 제공 내용은 남기는 운영 지시를 둔다. 완료 확인을 서두르지 않는다.

바로 쓸 문장:
- “차량이 P3로 이동하는 동안, 이제 이쪽 로봇암의 동작을 보겠습니다.”
- “팔레트가 내려놓인 것을 보셨습니다. 이제 화면에서 P3의 재고와 차량의 적재 상태를 차례로 확인하겠습니다.”
- “방금 본 이송을 고객 현장의 한 구간에서 시험하고, 작업 시간과 사람이 개입한 단계를 정리하는 서비스를 제안하려 합니다.”

판정: 조건부 수용. 시선 전환과 지연 시 축약 구간을 명시하면 현장 진행에 적합하며, 실제 20분·시연 5분 달성 여부는 아직 확인하지 않았다.
