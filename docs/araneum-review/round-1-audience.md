# 1회 — 청중 이해 관점

핵심 판단: 기존 대본의 현장 시선 안내와 새 원고의 운영자 상황극을 결합하면 좋다. 기존은 무엇을 볼지 명확하지만 도입이 추상적이고, 새 원고는 운반 이유가 선명하지만 용어·번호·기술 설명 때문에 눈앞의 공간으로 돌아오기 어렵다.

1. 공간과 용어: 기존 20행과 새 원고 9행 모두 팔레트를 설명하지 않고 시작한다. 기존 72~78행의 도크·Pallet Zone·Pallet 3·docker는 한꺼번에 등장한다. 새 15행의 1·2순위까지 합치면 P3를 세 번째 우선순위로 오해할 여지가 있다. 팔레트 실물을 먼저 가리키고, 출발지·목적지·임시 보관 위치를 대응시켜야 한다. 대기 구역은 차량 주차장이 아니라 물건을 잠시 놓는 곳임을 밝혀야 한다.

2. 흐름의 우회: 새 17~19행과 95~99행은 개별 ID 문제를 두 번 꺼낸다. 초심자에게 불필요한 의문을 만들며 기술명 요약(65행)까지 기억 부담을 더한다. 본문에서는 운반할 물건·갈 곳·완료 여부에 집중하고 ID는 질의응답으로 옮기는 편이 낫다. ‘전장’도 ‘시연 공간’으로 바꾼다.

3. 시연 연결: 새 원고에는 동작을 시작하고 관찰하는 구간이 없다. 기존 110~168행의 5분 구성을 유지하되 차량→로봇암→화면의 전환을 말로 알린다. 동시 동작을 자동 인계로 이해하지 않도록 설명하고, P3 하역을 끝낸 뒤 별도 주행의 정지·취소를 보여준다는 경계를 들려줘야 한다.

바로 쓸 문장:
- “이 물건 받침대가 팔레트이고, 도크는 물건을 받아 출발하는 곳, P3는 오늘 내려놓을 목적지입니다.”
- “1순위와 2순위는 처리 순서이고, P3는 장소 이름이며, 목적지에 자리가 없을 때 물건을 잠시 놓는 곳이 대기 구역입니다.”
- “먼저 차량을 보시고 이어 로봇암과 화면을 보겠습니다. 하역 결과를 확인한 뒤에는 별도 주행으로 정지와 취소를 보여드리겠습니다.”

판정: 재수정. 새 원고의 문제 제기와 기존의 현장 진행을 통합하되, 번호 구분과 시연 관찰 순서를 먼저 고정한다.
