# 2회차 기술 관점 검토

검토 대상: draft-v1.md, evidence-notes.md.

핵심 판단: 지도 생성과 운행 중 위치추정, 산업용 적용과 소형 실증, 가상 검토와 처리량 검증을 분리해 1회차의 주요 우려가 해소됐다. 포화 대기 규칙은 추가 근거로 문서·구현 확인 수준까지 높아졌으므로 1회차의 사용자 정보 분류를 갱신한다. 단순 기술명 나열도 줄었다.

1. 07:00–10:00의 “목적지 근처까지 가는 주행” 다음 Auto Dock 설명은 P3 도착 후 정렬·적재하는 순서로 들릴 수 있다. 실제 정상 흐름은 도크 접근→Auto Dock 적재 완료→P3 주행→포크 하역이다. 기술마다 정의를 더하기보다 한 팔레트의 이동 순서로 연결해야 한다. Auto Dock은 정렬만 성공했다고 적재 완료로 처리하지 않는다.
2. 같은 구간의 Open-RMF 일반 정의와 “저희가 확인한 현재 구조”가 연이어 나와, 본 프로젝트의 두 차량 연동까지 확인됐다는 인상이 남는다. 관제의 작업·이동 일정 조정과 차량의 실제 주행을 직접 설명하고, Open-RMF 적용 단계는 사용자 답변에 맞춰 한 문장으로 확정한다. 기술명을 빼더라도 이 역할 설명은 유지할 수 있다.
3. 시연의 “분류까지 연속 실행하는지는 … 구분해서 봐주시면”은 청중에게 구현 범위 판단을 맡긴다. 현재 보여주는 로봇암 동작과 차량 하역에 의해 자동으로 시작되는 후속 공정을 명확히 나눈다. 02:00–04:00의 대기 재이송도 ‘입고 위치가 비었을 때’라고 하면 실제 조건을 더 쉽게 전달한다.

교체 문장:

- “차량은 도크에서 팔레트에 맞춰 정렬하고 적재를 마친 뒤 P3로 이동해 팔레트를 내려놓습니다.”
- “관제는 작업과 이동 순서를 조정하고, 차량의 주행 기능은 전달받은 목적지까지 실제 이동을 수행합니다.”
- “오늘 로봇암은 별도로 동작을 보여드리며, 차량의 하역 완료와 후속 작업을 자동으로 이어주는 것은 다음 확장 단계입니다.”

판단: 조건부 수용. 역할 구분은 좋아졌고, 적재·이동 순서와 Open-RMF 적용 단계, 로봇암 인계를 최소 수정하면 재설명하기 쉬운 대본이 된다.
